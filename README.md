# Alias # Alias for English Learners

Веб-игра для отработки английской лексики в формате «Alias» / Catchphrase:
команда объясняет слово без однокоренных подсказок, пока не закончится
время. Чистый **HTML/CSS/JavaScript**, без фреймворков и сборщиков —
открывается прямо в браузере.

**by QuAsi**

## Как играть

1. **Menu** → *start the game*.
2. **Choose your level** — 5 уровней сложности, у каждого свой цвет; при
   выборе игра подгружает (`fetch`) соответствующий словарь из
   `dictionaries/`.
3. **Choose your topics** — темы строятся из реально загруженного словаря;
   пока не выбрана хотя бы одна тема, кнопка «Next» неактивна.
4. **Round settings** — время на раунд, количество раундов, штраф за skip.
5. **Teams** — от 2 до 6 команд, добавление/удаление.
6. **Игра**: экран «твой ход» → карточка слова с пиксельным таймером,
   кнопки *Got it* / *Skip*, звуки и эффекты → экран результатов раунда
   (можно поправить ✓/✕ тапом, если нажали не туда) → следующая
   команда/раунд.
7. **Финал**: таблица очков всех команд, трофей и конфетти.

Пауза (⏸ в углу игрового экрана) позволяет выйти в меню, не потеряв счёт.

## Структура проекта

```
index.html
styles/
  style.css              ← основные стили, анимации, звуковые эффекты кнопок
  adaptive_style.css     ← адаптивность
scripts/
  state.js               ← глобальное состояние игры
  effects.js              ← визуальные эффекты (лучи, burst)
  audio.js                ← звуки на Web Audio API
  dictionary.js           ← парсинг словарей из .txt
  navigation.js           ← переходы между экранами, шаги визарда
  game.js                 ← логика раунда, таймер, слова
  results.js              ← экран результатов раунда
  pause.js                ← меню паузы
  endgame.js              ← финальный экран, конфетти, трофей
dictionaries/
  elementary.txt
  pre-intermediate.txt
  intermediate.txt
  intermediate-plus.txt
  upper-intermediate.txt
```

`index.html` подключает `styles/` через `<link>` и все файлы `scripts/`
через `<script src="...">` в строго определённом порядке:

```
state → effects → audio → dictionary → navigation → game → results → pause → endgame
```

Порядок важен для первых четырёх модулей — они выполняют код сразу при
загрузке страницы (строят список уровней, темы, команды и т.п.) и
используют переменные из `state.js`; остальные пять состоят из объявлений
функций и от порядка не зависят.

Открывать нужно `index.html` — он сам подтянет остальные файлы, главное
держать `styles/`, `scripts/` и `dictionaries/` рядом, на одном уровне.

## Формат словаря (.txt)

```
## Название категории
слово
слово
слово с подсказкой | 🗣 Say: "..."

## Следующая категория
слово
слово
```

- `## ` в начале строки — новая категория, всё после неё — её название,
  как оно покажет в игре.
- Дальше — слова, по одному на строку, до следующей `## ` или конца файла.
- Подсказка добавляется через `" | "` после слова, например:
  `do the ironing | 🗣 Say: "do the ironing"`. Сейчас она не выводится на
  игровом экране — просто хранится, готовая к использованию.
- Строки, начинающиеся с `//`, — комментарии, игра их игнорирует.
- Порядок категорий в файле = порядок, в котором они появятся в игре.

Текущее наполнение: **Elementary** (20 категорий, 407 слов),
**Pre-Intermediate** (23 категории, 421 слово), **Intermediate**
(20 категорий, 507 слов), **Upper-Intermediate** (26 категорий,
637 слов). **Intermediate Plus** пока остаётся пустым шаблоном — готового
списка слов под этот уровень ещё нет.

## Запуск локально

Открытие `index.html` двойным кликом (`file://...`) не подойдёт — браузер
блокирует `fetch()` локальных файлов из соображений безопасности, и
словари не загрузятся. Нужен любой простой локальный сервер, например:

```
python3 -m http.server 8000
```

и открыть `http://localhost:8000/`.

## Публикация на GitHub Pages

1. В репозитории должны лежать (на одном уровне) `index.html`, папки
   `styles/`, `scripts/` и `dictionaries/`.
2. **Settings → Pages** → Source: ветка `main`, папка `/ (root)`.
3. Через пару минут игра будет доступна по адресу вида
   `https://<логин>.github.io/<репозиторий>/`.

## Технологии

Vanilla JavaScript (без фреймворков), CSS custom properties и
`color-mix()` для тем уровней, пиксельные скруглённые углы через
`clip-path`, Web Audio API для звука, `fetch` для загрузки словарей.

## Как устроена игра

1. **Menu** → **Choose your level** — 5 уровней с отдельным цветом каждый;
   при выборе игра подгружает (`fetch`) соответствующий `.txt` из
   `dictionaries/`.
2. **Choose your topics** — категории строятся из реально загруженного
   словаря (если словарь пуст — пилюль не будет, и появится подсказка об
   этом; кнопка «Next» заблокирована, пока не выбрана хотя бы одна тема).
3. **Round settings** → **Teams** → **Play**.
4. Дальше игра идёт по кругам: **экран хода команды** («Team A, ваш ход») →
   **экран игры** (слово + пиксельный таймер по контуру карточки, Got it /
   Skip, звуки, вспышка) → по истечении времени — **экран результатов**
   (можно тапом поправить ✓/✕, если по ошибке нажали не туда) → следующая
   команда/раунд → в конце — **экран победителя** с таблицей очков всех
   команд, конфетти и фанфарами.
5. Пауза (⏸ в углу экрана игры) позволяет включить/выключить звук или выйти
   в меню, не потеряв счёт.

```

слово
слово с подсказкой | 🗣 Say: "..."

## Следующая категория
слово
слово
```

Правила:
- `## ` (два `#` и пробел) в начале строки — новая категория, всё после
  этого — её название, как оно покажет в игре.
- Дальше — слова, по одному на строку, до следующей `## ` или конца файла.
- Подсказка (как в блоках make/do, verb+to/ing) добавляется через `" | "`

  не показывается в игровом экране (в дизайне для неё пока нет отдельного

- Строки, начинающиеся с `//` — комментарии, игра их полностью игнорирует.
  Можно оставлять сколько угодно заметок для себя.
- Пустые строки не обязательны, но помогают читать файл.
- Порядок категорий в файле = порядок, в котором они появятся в игре.

## Публикация на GitHub Pages

1. Создайте репозиторий, положите в корень `index.html`, `style.css`,
   `script.js` и папку `dictionaries/` со всеми `.txt` — все рядом, на
   одном уровне.
2. В настройках репозитория → **Settings → Pages** → Source: выберите
   ветку (обычно `main`) и папку `/ (root)`.
3. Через минуту-другую игра будет доступна по адресу вида
   `https://<ваш-логин>.github.io/<репозиторий>/` — браузер сам откроет
   `index.html`, имя файла в адресе указывать не нужно.

**Важно:** если открыть `index.html` просто двойным кликом с диска
(`file://...`), браузер может заблокировать `fetch()` локальных файлов
из соображений безопасности — уровень не загрузится, появится сообщение
об ошибке прямо на экране выбора уровня. Для локальной проверки перед
публикацией проще всего поднять любой простой сервер в папке проекта,
например:

```
python3 -m http.server 8000
```

и открыть `http://localhost:8000/` (или `http://localhost:8000/index.html`).

## Что проверено

Логика полностью прогнана автоматическим тестом (без браузера, но с
реальным выполнением всего кода): загрузка словаря, пустой словарь,
ошибка загрузки, выбор тем, ходы нескольких команд, штраф за скип,
исправление результата тапом, переход между раундами, итоговая таблица
и экран паузы — всё отработало без ошибок.

Что не входит в эту версию (по сравнению с самым первым простым
вариантом): встроенный редактор слов внутри игры. Слова сейчас
редактируются только через сами `.txt`-файлы. Если он вам нужен —
скажите, добавлю отдельным шагом.

## На будущее: импорт слов в стиле Quizlet

Вы упомянули, что в будущем хотите вставлять слова так же, как это
делается в Quizlet — списком с выбором разделителя между словом/переводом
и между карточками. Нынешний формат (`## Категория` + слова по строкам,
`|` перед подсказкой) выбран так, чтобы позже было легко добавить экран
«Импорт словаря»: текстовое поле, куда вставляется список, плюс выбор
разделителей — и результат конвертируется в этот же формат `.txt` или
сразу подгружается в игру. Когда будете готовы — можно добавить такой
экран отдельным шагом.
