# Alias — English File (структура для GitHub)

## Файлы

```
index.html                       ← разметка страницы (все экраны игры)
style.css                        ← все стили, включая анимации и звук. эффекты кнопок
script.js                        ← вся логика игры (JS), включая звуки и конфетти
dictionaries/
  elementary.txt                 ← словарь уровня Elementary
  pre-intermediate.txt           ← словарь уровня Pre-Intermediate
  intermediate.txt               ← словарь уровня Intermediate
  intermediate-plus.txt          ← словарь уровня Intermediate Plus
  upper-intermediate.txt         ← словарь уровня Upper-Intermediate
```

Это версия на основе вашего дизайна (`alias_preview` с пиксельными кнопками,
звуковыми эффектами, конфетти и анимациями) — тот же внешний вид, но с полной
рабочей логикой игры и словарями, которые подгружаются из `.txt`-файлов, а не
зашиты в код.

`index.html` подключает `style.css` через `<link>` и `script.js` через
`<script src="...">` — стандартная структура из трёх файлов. Открывать нужно
именно `index.html`, он сам подтянет остальные два (главное — держать все
файлы и папку `dictionaries/` рядом, на одном уровне).

## Как устроена игра

1. **Menu** → **Choose your level** — 5 уровней с отдельным цветом каждый;
   при выборе игра подгружает (`fetch`) соответствующий `.txt` из
   `dictionaries/`.
2. **Choose your topics** — категории строятся из реально загруженного
   словаря (если словарь пуст — пилюль не будет, и появится подсказка об
   этом; кнопка «Next» заблокирована, пока не выбрана хотя бы одна тема).
3. **Round settings** → **Teams** → **Play**.
4. Дальше игра идёт по кругам: **экран хода команды** («Team A, ваш ход») →
   **экран игры** (слово + пиксельный таймер по контуру карточки, Got it /
   Skip, звуки, вспышка) → по истечении времени — **экран результатов**
   (можно тапом поправить ✓/✕, если по ошибке нажали не туда) → следующая
   команда/раунд → в конце — **экран победителя** с таблицей очков всех
   команд, конфетти и фанфарами.
5. Пауза (⏸ в углу экрана игры) позволяет включить/выключить звук или выйти
   в меню, не потеряв счёт.

## Формат словаря (.txt)

```
## Название категории
слово
слово
слово с подсказкой | 🗣 Say: "..."

## Следующая категория
слово
слово
```

Правила:
- `## ` (два `#` и пробел) в начале строки — новая категория, всё после
  этого — её название, как оно покажет в игре.
- Дальше — слова, по одному на строку, до следующей `## ` или конца файла.
- Подсказка (как в блоках make/do, verb+to/ing) добавляется через `" | "`
  после слова: `do the ironing | 🗣 Say: "do the ironing"`. Сейчас подсказка
  не показывается в игровом экране (в дизайне для неё пока нет отдельного
  места) — она просто хранится и готова к использованию, если позже
  добавите под неё блок в интерфейсе.
- Строки, начинающиеся с `//` — комментарии, игра их полностью игнорирует.
  Можно оставлять сколько угодно заметок для себя.
- Пустые строки не обязательны, но помогают читать файл.
- Порядок категорий в файле = порядок, в котором они появятся в игре.

Сейчас четыре словаря заполнены реальными словами: **Elementary** (20
категорий, 407 слов), **Pre-Intermediate** (23 категории, 421 слово),
**Intermediate** (20 категорий, 507 слов) и **Upper-Intermediate**
(26 категорий, 637 слов) — все перегнаны из ваших рабочих `.txt`-файлов
преподавателя, сами слова не менялись, менялось только оформление
заголовков под формат игры. **Intermediate Plus** пока остаётся пустой
заготовкой — готового списка под этот уровень ещё нет.

## Публикация на GitHub Pages

1. Создайте репозиторий, положите в корень `index.html`, `style.css`,
   `script.js` и папку `dictionaries/` со всеми `.txt` — все рядом, на
   одном уровне.
2. В настройках репозитория → **Settings → Pages** → Source: выберите
   ветку (обычно `main`) и папку `/ (root)`.
3. Через минуту-другую игра будет доступна по адресу вида
   `https://<ваш-логин>.github.io/<репозиторий>/` — браузер сам откроет
   `index.html`, имя файла в адресе указывать не нужно.

**Важно:** если открыть `index.html` просто двойным кликом с диска
(`file://...`), браузер может заблокировать `fetch()` локальных файлов
из соображений безопасности — уровень не загрузится, появится сообщение
об ошибке прямо на экране выбора уровня. Для локальной проверки перед
публикацией проще всего поднять любой простой сервер в папке проекта,
например:

```
python3 -m http.server 8000
```

и открыть `http://localhost:8000/` (или `http://localhost:8000/index.html`).

## Что проверено

Логика полностью прогнана автоматическим тестом (без браузера, но с
реальным выполнением всего кода): загрузка словаря, пустой словарь,
ошибка загрузки, выбор тем, ходы нескольких команд, штраф за скип,
исправление результата тапом, переход между раундами, итоговая таблица
и экран паузы — всё отработало без ошибок.

Что не входит в эту версию (по сравнению с самым первым простым
вариантом): встроенный редактор слов внутри игры. Слова сейчас
редактируются только через сами `.txt`-файлы. Если он вам нужен —
скажите, добавлю отдельным шагом.

## На будущее: импорт слов в стиле Quizlet

Вы упомянули, что в будущем хотите вставлять слова так же, как это
делается в Quizlet — списком с выбором разделителя между словом/переводом
и между карточками. Нынешний формат (`## Категория` + слова по строкам,
`|` перед подсказкой) выбран так, чтобы позже было легко добавить экран
«Импорт словаря»: текстовое поле, куда вставляется список, плюс выбор
разделителей — и результат конвертируется в этот же формат `.txt` или
сразу подгружается в игру. Когда будете готовы — можно добавить такой
экран отдельным шагом.
