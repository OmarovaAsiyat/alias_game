// СЛОВАРЬ ДЛЯ ИГРЫ ALIAS — Intermediate Plus
// ═══════════════════════════════════════════════════════════
//
// Этот файл читает игра (alias.html) через fetch() и строит из него
// список категорий и слов. Всё, что начинается с "//", игра
// игнорирует — это место для ваших заметок, оно НЕ попадёт в игру.
//
// ФОРМАТ:
//
//   ## Название категории
//   слово
//   слово
//   слово с подсказкой | 🗣 Say: "..."
//
// Правила:
//   1. Строка "## " (два "#" и пробел) начинает новую категорию.
//      Всё после "## " — название категории, как оно будет
//      показано в игре.
//   2. Каждое следующее слово — на отдельной строке.
//   3. Если слову нужна подсказка (как в блоках make/do,
//      verb+to/ing) — допишите её через " | " после слова:
//      do the ironing | 🗣 Say: "do the ironing"
//   4. Пустые строки можно ставить для читаемости — они
//      ни на что не влияют.
//   5. Порядок категорий в файле = порядок в игре.
//
// Пока файл пуст — в игре при выборе уровня Intermediate Plus появится
// сообщение "словарь пока пуст". Раскомментируйте пример ниже
// (уберите "// " в начале строк) или добавьте свои категории,
// когда будете готовы — и всё заработает.
//
// Пример:
// ## Days of the week
// Monday
// Tuesday
// Wednesday
// weekend
//
// ## Countries
// Spain
// the United States
// Germany
